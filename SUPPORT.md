# Timebox YouTube Blocker Support

For support with Timebox YouTube Blocker, open a GitHub issue:

https://github.com/vikramsundar2004-collab/Timebox-Youtube-Blocker-support-and-home/issues

## Common Fixes

### YouTube is not blocked

1. Open Chrome and go to `chrome://extensions`.
2. Make sure Timebox YouTube Blocker is enabled.
3. Make sure Developer mode is enabled if you installed the direct download version.
4. Refresh YouTube or close and reopen the YouTube tab.
5. If a break is active, wait for the timer to finish or click **End break now**.

### No breaks are left

You get three 20-minute YouTube breaks per local day. After the third break, YouTube stays blocked until the next daily reset.

### How to remove the extension

Go to `chrome://extensions`, find Timebox YouTube Blocker, then click **Remove**.
