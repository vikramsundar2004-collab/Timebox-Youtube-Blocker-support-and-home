Install in Chrome

Choose the installer ZIP if you are on Windows. Use the manual ZIP if your browser blocks command files or if you want to inspect the package first.

Windows helper

  1. Download and extract install-timebox-youtube-blocker-windows.zip.
  2. Open install-timebox-youtube-blocker.cmd.
  3. If Windows asks, choose Run anyway only if you trust this project.
  4. The helper opens chrome://extensions and the extracted folder.
  5. Turn on Developer mode.
  6. Click Load unpacked and select TimeboxYouTubeBlocker.

Manual ZIP

  1. Download timebox-youtube-blocker.zip.
  2. Right-click the ZIP and choose Extract All.
  3. Open Chrome and go to chrome://extensions.
  4. Turn on Developer mode.
  5. Click Load unpacked and select the extracted folder.

What users see

YouTube starts blocked. A break unlocks YouTube for 20 minutes, and the daily limit resets the next day.
