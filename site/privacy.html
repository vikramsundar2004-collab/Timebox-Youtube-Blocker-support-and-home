Privacy

Privacy Policy

Timebox YouTube Blocker is designed to do one job: block YouTube by default and allow three timed breaks per day.

Extension data

The extension stores break timer state, daily break count, and extension settings locally in Chrome using Chrome storage. This local extension data is not sold, shared, or transmitted to our servers.

Website and payment data

If you buy the extension through a website checkout, payment processing is handled by Stripe. The website may store the email address attached to a paid order so customers can recover access later.

Permissions

The extension uses YouTube-related host permissions only to block or redirect YouTube pages, YouTube embeds, and related video requests. It does not collect page content for advertising or sell user data.

Contact

For privacy or support questions, use the support link on this site.
