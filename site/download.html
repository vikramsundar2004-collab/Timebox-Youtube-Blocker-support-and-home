Install Timebox today.

The Chrome Web Store review can take time. For class demos, use the Windows helper below. It downloads the extension, extracts it automatically, opens Chrome's extension page, and opens the exact folder to select.

Easiest install on Windows

  1. Click Download Windows helper.
  2. Open the downloaded file named install-timebox-youtube-blocker.cmd.
  3. If Windows asks for confirmation, choose Run anyway only if you trust this class project.
  4. The helper opens Chrome extensions and opens the extracted extension folder for you.
  5. In Chrome, turn on Developer mode in the top-right.
  6. Click Load unpacked.
  7. Select the folder the helper opened: TimeboxYouTubeBlocker.
  8. Open YouTube to confirm it redirects to the blocked page.

Manual install if the helper is blocked

  1. Click Download ZIP manually.
  2. Right-click the ZIP and choose Extract All.
  3. Open Chrome and go to chrome://extensions.
  4. Turn on Developer mode in the top-right.
  5. Click Load unpacked.
  6. Select the extracted folder.

What to expect

YouTube is blocked by default. Click "Give me a break" to unlock YouTube for 20 minutes. You get three breaks per local day, then the blocker stays active until tomorrow.
