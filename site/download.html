Chrome install steps

  1. Extract the Windows installer ZIP and open install-timebox-youtube-blocker.cmd.
  2. Open chrome://extensions.
  3. Turn on Developer mode.
  4. Click Load unpacked.
  5. Select the extracted extension folder.
  6. Open YouTube to confirm the blocker page appears.

Using an iPhone?

Scan the QR code to save or share the download page, then open the same link on a Windows, Mac, or Chromebook computer with Chrome. Chrome on iPhone can send an extension to desktop Chrome after Chrome Web Store approval, but it cannot run the extension on the iPhone itself.
